# simulador-escalonamento-processos
Simulador de algoritmos de escalonamento de processos desenvolvido para a disciplina de Sistemas Operacionais.

## Sobre o projeto

O projeto consiste no desenvolvimento de um simulador de escalonamento
de processos, permitindo analisar o funcionamento de diferentes
algoritmos de escalonamento.

## Algoritmos que serão implementados

- FCFS (First Come, First Served)
- SJF (Shortest Job First)
- Prioridade Não-Preemptivo
- Prioridade Preemptivo
- Round-Robin.

## Tecnologias

- Python

## Observações

Projeto desenvolvido como atividade acadêmica da disciplina de
Sistemas Operacionais.

Parte do código-base foi fornecida pelo professor como material de apoio
para a implementação das funcionalidades.
